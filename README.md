# مساعد الحوكمة الأكاديمية للمقرر (NotebookLM)

برومت تخصيص لدفتر NotebookLM يحوّله إلى مساعد حوكمة أكاديمية يولّد أسئلة اختيار من متعدد بصيغة AIKEN (جاهزة للاستيراد في مودل) ومخرجات تدريسية مرتبطة بمخرجات التعلم (CLOs) ومقيّدة بالمصادر المرفوعة في الدفتر.

## الملفات

| الملف | الوصف |
| :--- | :--- |
| `index.html` | دليل استخدام تفاعلي في ملف واحد، يتضمن زر نسخ مباشر للبرومت ورسومًا إرشادية وتبويبًا لمميزات الدفتر. يعمل دون اتصال بالإنترنت. |
| `prompt.txt` | نص البرومت وحده، للصقه في خانة تعليمات الدفتر. |

## الاستخدام

1. افتح صفحة الدليل (GitHub Pages) أو ملف `index.html` محليًا.
2. انسخ البرومت بزر النسخ، أو من `prompt.txt`.
3. الصقه في إعدادات تخصيص المحادثة في دفتر NotebookLM بعد رفع المصادر.

## تنبيه

البرومت يقلّل الخروج عن المصادر ولا يضمن منعه. راجع الاقتباسات ومفتاح الإجابة يدويًا قبل اعتماد أي اختبار.
